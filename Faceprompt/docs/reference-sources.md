# 参考来源与内部素材策略

## 使用原则
这套库的参考来源分成两类：

1. 人像摄影方法论来源，用来提炼光线、构图、环境叙事和真实肤质表现。
2. 发型编辑来源，用来提炼轮廓、长度分区、层次、纹理、刘海和发尾处理。

当前仓库只内置来源链接与文字提炼，不自动抓取外部图片。这样可以保留来源链路，同时避免把版权策略做得过于激进。内部团队如果需要补充缩略图，可按 [assets/reference-thumbnails/README.md](/home/lcy/Faceprompt/assets/reference-thumbnails/README.md) 的规则手动加入低分辨率参考。

## 后续补图建议
- 每张内部参考缩略图命名使用 `source-id__short-description.jpg`
- 只保留低分辨率、低体积版本
- 在新增缩略图时，同步记录来源链接、抓取日期和用途说明
- 如果目标仓库需要公开发布，移除所有缩略图，只保留来源链接和文字提炼
