# 国内平台发型分类清单

更新时间：2026-03-23

这份清单是给实际使用场景准备的分组版。

使用建议：

- 一级类目用于前端筛选和模板导航。
- 二级项目保留具体发型名，方便搜图、建模板、后续生成映射。
- 刘海不要并入主发型，单独做标签。

## 男生发型分类

### 1. 短发基础款

适合做“清爽”“少年感”“日常通用”类模板。

- 前刺头
- 法式短碎发
- 微分碎盖
- 摩根碎盖
- 栗子头
- 圆寸
- 板寸 / 短平头
- 渐变寸头

合计：8 类

### 2. 分线露额款

适合做“韩系”“轻熟”“通勤”“精致感”类模板。

- 韩系三七分
- 逗号刘海发型
- 中分微分
- 侧分油头
- 复古背头

合计：5 类

### 3. 蓬松烫发款

适合做“显发量”“修头型”“热门男生烫发”类模板。

- 纹理烫
- 气垫烫
- 定位烫
- 钢夹烫
- 锡纸烫
- 烟花烫
- 羊毛卷
- 法式慵懒卷

合计：8 类

### 4. 个性趋势款

适合做“潮流”“街头”“风格化”类模板。

- 狼尾发型
- 鲻鱼头

合计：2 类

### 5. 中长发 / 扎发款

适合做“氛围感”“日系”“艺术感”类模板。

- 日系中长发
- 武士头 / 半扎

合计：2 类

### 男生汇总

- 短发基础款：8 类
- 分线露额款：5 类
- 蓬松烫发款：8 类
- 个性趋势款：2 类
- 中长发 / 扎发款：2 类
- 男生总计：25 类

## 女生发型分类

### 1. 短发基础款

适合做“清爽”“减龄”“轮廓感强”类模板。

- 一刀切波波头

- 齐脸短发

- 日系苹果头
- 法式推边短发
- 少年感超短发
- 赫本短发

合计：8 类

### 2. 中短发 / 锁骨发

适合做“通用女主图”“最不容易翻车”的模板。

- 锁骨发
- 辛芷蕾锁骨发
- 高层次锁骨发
- 微卷锁骨发
- 齐肩发

合计：5 类

### 3. 中长发层次款

适合做“修脸”“轻盈”“高层次”“日常爆款”类模板。

- 高层次中长发
- 边缘层次剪
- 羽毛剪
- 狼剪
- 改良公主切
- 原版公主切 / 姬发式

合计：6 类

### 4. 长直发款

适合做“新中式”“清冷感”“东方气质”类模板。

- 黑长直

- 新中式长直发

合计：3 类

### 5. 卷发 / 烫发款

适合做“氛围感”“成熟感”“显发量”类模板。

- 法式慵懒卷
- 韩式气垫烫
- 木马卷
- 水波纹
- 人鱼卷
- 羊毛卷
- 云朵烫
- 蛋蛋卷 / 蛋卷头
- 麦穗卷
- 鱼尾烫
- 港风大波浪

合计：11 类

### 女生汇总

- 短发基础款：8 类

- 中长发层次款：6 类
- 长直发款：3 类

- 女生总计：33 类
