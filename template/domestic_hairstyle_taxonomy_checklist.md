# 国内平台发型归一清单

更新时间：2026-03-23

这份清单按国内平台常见叫法做归一整理，优先覆盖小红书、抖音、美发内容号里高频出现的主发型名称。

统计口径：

- 男生主发型：25 类
- 女生主发型：33 类
- 刘海标签：8 类

说明：

- 这里统计的是适合做模板主类的发型，不包含马尾、丸子头、编发、盘发等一次性造型。
- 同义词做了合并，避免同一类发型因为平台命名不同而重复建类。
- 刘海建议单独做标签，不直接并入主发型 ID。

## 推荐落库方式

- 主表分为 `male`、`female` 两个主类。
- 每个主类保存 `canonical_name`、`aliases`、`length_group`、`style_group`。
- 刘海单独作为标签表，避免主发型和刘海组合爆炸。
- 搜图时优先用 `归一名称 + 常见别名` 联合检索。
