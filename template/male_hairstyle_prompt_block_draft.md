# 男生发型扩展 Prompt Block 草案

## 1. 目的

- 这份草案对应即山川 126 条视频提炼出的 33 个主发型子类。
- 推荐算法层保留细分别名；生图层统一回落到主结构与 modifier。
- 后端兼容草案文件见 `male_hairstyle_expanded.json`。

## 2. 标准装配顺序

1. 主结构：长度、侧区处理、顶区长度、走向、分线、刘海基底。
2. 刘海 modifier：括号刘海、逗号刘海、长刘海、侧刘海。
3. 风格 modifier：港风、通勤清爽。
4. 收尾 modifier：凌乱纹理、湿发质感。
5. 发色 block：当前默认使用深色统一染。

## 3. 主结构清单

### 立体前刺

- 主结构 ID：`dimensional_forward_spike`
- 分类：`前刺刺感类` / `清爽短发`
- 别名：立体前刺、凌乱前刺、立体短刺、立体上刺
- Prompt Core：发型改成立体前刺，两侧保持低体积，顶部短发向前上支撑，轮廓更挺更立体，显颅顶、显精神。
- 建议叠加 modifier：modifier_messy_texture
- Guardrails：必须保留向前向上，支撑感更强的主走向和顶部更竖直、立体轮廓。；两侧紧贴头型不能丢，不能塌成普通short。；前区必须符合“短碎前区，轻露额”和“无”的结构关系。

### 纹理前刺

- 主结构 ID：`textured_forward_spike`
- 分类：`前刺刺感类` / `清爽短发`
- 别名：纹理前刺、纹理短刺分、纹理上刺、上翘前刺
- Prompt Core：发型改为纹理前刺，两侧贴紧，顶部保留更明显的纹理和向上翻起的短束，发丝细碎而清楚，突出颅顶和发量。
- 建议叠加 modifier：无
- Guardrails：必须保留向前并向上翻起的主走向和顶部立体，束感更密轮廓。；两侧短且服帖不能丢，不能塌成普通short。；前区必须符合“前区短碎翻起”和“无或极弱分线”的结构关系。
- 备注：基础结构仍用前刺，纹理描述单独强化。
